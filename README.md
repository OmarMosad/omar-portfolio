# Omar Shehata — Game-Style Portfolio

Personal portfolio of **Omar Shehata**, Full-Stack Web & Telegram Developer (Web3, APIs & Backends).

A light, mobile-first, game-style single-page site: PRESS START loader with a walking pixel character,
a guided 7-stop tour, hidden coins that unlock the Bug Runner mini-game, a working secret terminal,
dark/light themes and full EN/AR (RTL) support. Vanilla HTML/CSS/JS — no build step, no dependencies (~356 KB total).

## Files
- `index.html` — the portfolio page
- `style.css` / `script.js` — styles and all logic + content data
- `cv.html` — printable résumé page
- `assets/` — Omar's photo, pixel-character sprites and project covers

## Deploy on Vercel
Import this repository in Vercel — framework preset: **Other**, no build command, root directory as-is.
